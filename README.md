# LunaBlanca · Sitio web

Sitio estático listo para GitHub Pages.

## Estructura
- `index.html` — la landing completa (una sola página)
- `img/` — fotos (.webp) y logos
- `.nojekyll` — evita que GitHub procese el sitio con Jekyll

## Publicar en GitHub Pages
1. Crea un repositorio (por ejemplo `lunablanca-web`).
2. Sube TODO el contenido de esta carpeta a la raíz del repositorio (index.html debe quedar en la raíz).
3. En el repositorio: Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / carpeta `/ (root)` → Save.
4. En 1–2 minutos el sitio queda en `https://TU-USUARIO.github.io/lunablanca-web/`.

## Cambiar el número de WhatsApp
Busca y reemplaza `593999999999` en `index.html` por el número real (código de país + número, sin + ni espacios).

## Cambiar fotos
Reemplaza los archivos en `img/` manteniendo el mismo nombre:
hero.webp · experiencia-1.webp · experiencia-2.webp · experiencia-3.webp · sendero.webp · mascotas.webp · noche.webp
